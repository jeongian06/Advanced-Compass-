# Advanced Compass++

An RPG-style compass for your Minecraft GUI! Track nearby mobs, players, and waypoints with customizable icons, distances, and settings.

![ac++preview](https://cdn.modrinth.com/data/cached_images/0007701cee56731f8455ac7606965bcb97b71748.png)

## Features & Settings

<details>
<summary>🧭 Compass Display</summary>

- **Show Mode:** Choose when the compass appears:
  - `ALWAYS_ON` — Always visible.
  - `MAIN_HAND` — Visible only while holding a vanilla compass in your main hand.
  - `BOTH_HAND` — Visible while holding a vanilla compass in either hand.
  - `ANY_SLOT` — Visible while a vanilla compass is anywhere in your inventory.
  - `OFF` — Turn off the advanced compass.
- **Show Coordinates:** Display your coordinates above or below the compass.
- **Coordinates Scale:** Adjust coordinate text size from 0.5× to 2×.
- **Compass Width:** Change the compass width.
- **Compass Height:** Adjust background height from 8 to 50.
- **Y Offset:** Move the compass down from the top of the screen (0–50).

</details>

<details>
<summary>👾 Icons & Entities</summary>

- **Icon Scale:** Resize mob, player, and waypoint icons from 0.5× to 2×.
- **Icon Generation Type:** Choose how icons are generated for modded mobs:
  - `HEAD_FIRST` — Try generating an icon from the mob's head first, then try its body if needed.
  - `FULL_BODY` — Generate an icon using the mob's full body.
  - `OFF` — Disable icon generation and use default icons.
- **Show Players:** Toggle player icons. NPCs may also be affected.
- **Group Entities:** Combine nearby mobs of the same type into one icon.
- **Group Distance:** Set the maximum distance between entities for grouping.
- **Distance:** Set the maximum detection range for entities. Entities beyond your render distance won't appear.

</details>

<details>
<summary>🎯 Compass Accuracy</summary>

- **View Angle:** Set the compass's field of view. For example, 90° covers 45° to either side of your viewing direction.
- **Angle Threshold:** Set the maximum angle at which icons remain visible, up to 180°. Higher values let icons stay visible longer as you turn away.
- **Hide Behind:** Hide mob icons when their entities are behind blocks.
- **Hide Overlapped:** Hide icons covered by other icons, showing only the topmost one.
- **Overlap Threshold:** Set how many pixels icons can overlap before one is hidden.

</details>

<details>
<summary>⚙️ Extra Options</summary>

- **Move Bossbar:** Move the vanilla boss bar below the compass. Disable this if modded boss bars display incorrectly.
- **Show Distance:** Display distances below icons.
- **Death Waypoint:** Automatically create a waypoint when you die.

</details>
